### Phase 4: Code Quality

- New module `src/usage_shape.py` is dependency-free (stdlib `datetime` +
  `structlog` only) — no Qt, no I/O, no network. That is what makes it both
  unit-testable in isolation and copyable verbatim into
  `peripheral-battery-monitor` under spec 015.
- **Duplication removed**: `build_tui_view` grew a second bar-grid construction
  for the credits shape, so the column layout + `ProgressBar` assembly was
  extracted to `_build_bar_grid()` and both shapes now share it. Net effect is
  one grid definition where the naive change would have left two.
- `severity_color()` added to `display.py` beside `usage_color()`, keeping all
  color-threshold logic in the one Qt-free module that already owns it.
- Detection is by data presence, not account type — no branching on
  `member_dashboard_available` or other permission flags, so a bucket rename does
  not require a code change.
- `ruff check` on every touched file: **All checks passed**. Seven pre-existing
  findings remain in `tests/test_config.py`, `tests/test_oauth.py`, and
  `tests/test_widget_logic.py` (unused imports, unused locals) — untouched, as
  they are outside this change's scope.
- Status: PASSED
